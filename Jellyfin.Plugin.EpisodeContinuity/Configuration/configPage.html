Episode Continuity

Warns viewers when the episode about to play is not the one that follows the previous episode because episodes in between are missing from the library. "Missing" means an episode the metadata provider knows about that has no file (Jellyfin's virtual episodes).

Turn the plugin off without uninstalling it.
By default only episodes the metadata provider knows about count as missing, so shows need a metadata match. With this on, a jump in the episode numbers on disk within a season (for example S01E01 followed by S01E03) also counts, even when the show has no metadata. Turn it off if your library has shows with intentionally irregular numbering.

Server warning (all clients)

When an episode starts that skips over missing episodes, the plugin can warn the viewer in two ways. The server warning below is pushed to whatever client started playback and works everywhere, best effort. The web interstitial in the next section is drawn by a script inside the Jellyfin web app and is more reliable there. A browser only ever sees one of the two: while the interstitial is enabled, it replaces the server warning in the web client.
Sent by the server after playback has already started, so the first seconds of the episode may play before the warning appears. Works on any client that supports display messages; some clients (for example Android TV) ignore them. Not shown in the web client while the web interstitial is enabled.
After warning a session about an episode, stay quiet if the same session starts the same episode again within this many seconds. This absorbs duplicate start reports and seeks. Set to 0 to warn on every start.

Web client script

Adds a small script to the Jellyfin web app at request time (no files are modified). Required for the two options below. Uses the File Transformation plugin when it is installed. Restart Jellyfin after changing this.
When the episode queued to autoplay is not the next one, the countdown dialog says which episodes are missing. Jellyfin only shows that countdown for episodes of 10 minutes or longer, about 30 seconds before the end.
The web-client version of the server warning above. The script holds the video before it starts and shows a dialog naming the missing episodes, with a countdown, a Continue button and a Go back button. While this is on, web sessions do not receive the server warning; other clients still do.
